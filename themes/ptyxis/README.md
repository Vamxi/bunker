# Bundled palettes

A lean set from [Ptyxis](https://gitlab.gnome.org/chergert/ptyxis) 50.1,
extracted from its resources unchanged: GNOME (used by the default `system`
theme), Dark Pastel, Solarized, Tango, VS Code, Horizon, High Contrast,
Dracula, and Nord. Palettes with light and dark variants appear as `name`
(dark) and `name-light`; Dracula and Nord keep bunk's versions. Dark Pastel
comes from the [Gogh](https://github.com/Gogh-Co/Gogh) collection (MIT).

bunker loads every `.palette` file here; add more to bundle them.
